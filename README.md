# ㄚ喬文字搜尋測試 002
獨立 Android App，ARM64，Android 8+。只讀取使用者選取的圖片，模型隨 APK 打包，不需要網路、不修改原圖。
預設中文＋英文；可切換英文、日文、韓文。每批使用同一個模型，選相同圖片可比較不同模型。原始辨識文字與耗時、失敗訊息、圖片 URI 儲存在 app 私有空間。搜尋採 NFKC、忽略大小寫及空白的子字串比對；不進行簡繁轉換或模糊搜尋。
測試：選 10–20 張實際截圖（繁中、英文、混合、模糊或監視器日期），依已知文字搜尋。點結果看原圖與完整原始文字，記錄漏搜。切飛航模式重新辨識。關閉重開確認索引保留。清除紀錄不刪除照片。
編譯：JDK 17、Android SDK 35、Gradle 8.9，執行 gradle :app:assembleRelease。測試簽章，勿用作正式長期版本。

002: 非除錯 release APK，專用簽章 v1/v2/v3，原生函式庫改由安裝程式解壓。若 001 曾成功安裝，需先解除安裝 001 才能換簽章。
