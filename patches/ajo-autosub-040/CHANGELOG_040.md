# ㄚ喬自動字幕 040｜漏句區間檢查與局部 Whisper 重辨識

基準：039 完整原始碼；未調整任何 iPhone HDR 匯出參數。

## 新功能（使用者啟動，避免自動誤判）

- 主畫面新增「檢查可能漏句（不改原字幕）」。利用既有 16 kHz 音訊與 `SpeechTiming.analyze` 尋找**音訊能量明顯、但字幕時間沒有覆蓋**的區段，列出最多 12 個候選。能量可能是音效、音樂，不視為已確認人聲。已有字幕時不自動增加或覆蓋。
- 點選候選可在原片時軸附近保留前後聲音語境（預設 ±1.5 秒，上限 18 秒）進行 **Whisper Small 本機二次辨識**；使用已下載模型，沒有新雲端成本。
- 單句編輯新增「用 Whisper 重辨識這段（先預覽，不覆蓋）」，可檢查**已被現有字幕時間覆蓋、但其實有重疊人聲**的區間。原來的字幕不會被自動取代。
- 重新辨識結果只作為**待人工確認的建議**。選「保留原文」就維持原樣；選「取用文字並校正」才將選取段文字替換並打開原本單句編輯畫面；選「新增並校正」才手動新增候選字幕。只替換文字，不自動改動原句的時間、格式、位置或其他句子。
- 重辨識使用的 PCM 區段採用 32 bytes/ms (16 kHz/mono/PCM16) 精確裁切；相對字幕時間會加回原片位移。

## 已知限制與驗證範圍

- 音量式語音活動偵測不是專業 VAD；重疊人聲通常落在原句時段內，**不能只靠漏句空白掃描**，所以另外提供單句局部重辨識。
- Whisper 局部重辨識仍可能產生錯誤中文字、重複或漏句。請先聽聲音，並自行判斷是否採用。沒有任何機制可以確保中文語音 100% 正確。
- 040 沒有下載或內建 MossFormer2、Large-v3 或 Turbo，也沒有強迫輸出中文或把錯誤漢字轉注音。
- iPhone HDR/HLG 色彩、60 fps、字幕匯出畫質本版均不改動，保留到 041 處理。
- 新增 `Version040Tests.java` 以純 Java 驗證候選區間、不改原字幕、上下文裁切、時間回填與實際 PCM 切片；**Android 實機表現仍須使用者測試**。
