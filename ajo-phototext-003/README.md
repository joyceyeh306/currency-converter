# ㄚ喬文字搜尋測試 003
以已實機使用的ㄚ喬計步器 003 建置規格重建獨立專案。AGP 8.9.2 / Gradle 8.11.1 / JDK17 / minSdk29 / targetSdk35；新 package tw.ajo.phototext，獨立 release 簽章。僅保留中文＋英文與英文模型，先驗證安裝與核心搜尋。無網路存取權限，原始照片只讀。照片選取、辨識、記錄及搜尋功能沿用 001。日韓模型延後整合。

## 004
保留 003 applicationId、簽章、資料檔 index.json、ML Kit 版本及辨識邏輯；Android 13+ 使用原生 Photo Picker 多選（系統上限），無法啟動時或較舊 Android 使用文件選擇器。根介面處理狀態列、導覽列、顯示切口及鍵盤 insets；批次顯示實際經過時間與每張辨識耗時平均值。更新前不必清除 003 資料。

## 005 啟動修正版
004 啟動閃退：移除 onCreate 早期直接存取 WindowInsetsController 的程式碼，沿用原主題系統列外觀，根 View 附著後才設定 safe-area；保留相片選擇器、耗時及原本 OCR、簽章、索引格式。實機閃退原因仍待驗證；未加大量掃描功能。

## 006 大量辨識
沿用 005 ML Kit 模型、簽章與安全邊距。SQLite WAL，逐張交易式寫入索引及待掃清單；保留舊 JSON 檔並一次性遷移。MediaStore 直接讀取相簿，預設最新 1000 張尚未索引的照片，也可選 3000/5000/10000/全部；相機與截圖依路徑辨識。已成功辨識（含無文字）且修改時間與大小相同者跳過，失敗項目可重新掃描。手動選圖與媒體庫不同 URI 可能重複；不做檔名猜測。關閉/離開 App 暫停，重新開啟按繼續，暫停時不計入總耗時。搜尋使用 SQLite Unicode 正規化子字串，分頁 100 筆，縮圖按可見列讀取。電量與電池溫度僅供參考。006 不是背景自動掃描，未刪除原始照片。

## 007 正式介面
006 的 IndexStore、ML Kit、簽章、相簿掃描與待處理資料庫保持不變。搜尋首頁清爽留白、暖白/青綠、最近搜尋（送出查詢或選取結果時記錄）、等寬縮圖網格、設定集中管理索引，手動更新可從首頁執行。全畫面照片檢視可雙指縮放、拖曳、分享原始 URI、複製或選取 OCR 文字。預覽使用最長邊約 3000 像素以下的取樣以控制記憶體；分享仍是原始檔。未加入 008 搜尋邏輯或 009/010 自動背景更新。

## 007a 介面修正
搜尋卡片加入 1dp 外框、1dp 陰影、6dp 內距、照片 10dp 圓角及 1dp 邊框、10dp 網格間距。兩行摘要以第一個命中關鍵字為中心，保留約 6 個字元的前文與後文；命中以黃色背景、深色粗體標示。全文也使用相同標示，自動捲到第一個命中附近。Unicode NFKC、忽略大小寫及空白映射回原文，沿用 007 原本的搜尋規則，不增加多關鍵字或簡繁轉換。資料庫、OCR、簽章不變。顯示版本及檔名 007a，Android versionCode 8；後續 008 必須至少 9。

## 008 強化搜尋
空白或全形＋分隔關鍵字，預設全部符合，可切換任一符合。Android ICU Traditional-Simplified 字形折疊（逐漢字）；不改原文，搜尋命中回映原字。既有 records 增加 folded 欄位並從原 OCR 一次遷移，無需辨識；photo_meta 獨立快取可取得的 MediaStore 相簿及日期。拍攝日期優先，缺失用修改/加入日期；不明日期排最後且不納入日期區間。指定相簿、相機、截圖、日期區間、新舊排序收進篩選對話框。手動 URI 可能缺少相簿資訊；簡繁字形不是地區用詞同義轉換。維持 007a 卡片和引擎。Android versionCode 9。

## 009 前景自動同步
預設開啟；開啟 App 或 MediaStore 異動後 debounce 檢查。只在完整照片讀取權限且 App 前景運作。逐掛載媒體卷建立完整快照，缺失 canonical URI 必須再次單筆查詢確認空結果才清資料庫；不可讀的卷、手動 picker/document URI 不主動刪除。比對既有 date_modified:size，未變更（包含無文字及同版本失敗）跳過，失敗可由手動更新重試；新照片預設繁中英文，變更時也刷新原有其他模式，更新檔名及相簿資料。沿用 006 持久化佇列，前景離開暫停，自動佇列重開可繼續，手動佇列須手動續掃。明確暫停/停止自動掃描或清除索引時關閉自動同步，可在設定重新啟用。手動更新保留；不含背景週期工作。既有 DB schema 2 不變。

## 012 模糊搜尋（跳過 010／011）
009 已驗證基準；不加入背景辨識或日韓模型。篩選頁可關閉模糊搜尋（預設開啟），完全離線。單字精確，兩字以上容許一組相似字，四字以上純漢字或英文字容許一處插入、刪除或替換；數字四位以上忽略常見分隔符號並容許一個 O/I/L/S/B/Z 字母誤辨，不容許任意數字替換。純數字含空格/日期電話分隔符視為整組數字。保留 AND/OR、簡繁、日期/相簿篩選。精確符合優先，近似次之，同級日期排序，黃色精確／橘色近似。使用既有 folded 欄位，不需 DB 遷移或 OCR 重跑。Android versionCode 13。
