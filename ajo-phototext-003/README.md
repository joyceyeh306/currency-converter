# ㄚ喬文字搜尋測試 003
以已實機使用的ㄚ喬計步器 003 建置規格重建獨立專案。AGP 8.9.2 / Gradle 8.11.1 / JDK17 / minSdk29 / targetSdk35；新 package tw.ajo.phototext，獨立 release 簽章。僅保留中文＋英文與英文模型，先驗證安裝與核心搜尋。無網路存取權限，原始照片只讀。照片選取、辨識、記錄及搜尋功能沿用 001。日韓模型延後整合。

## 004
保留 003 applicationId、簽章、資料檔 index.json、ML Kit 版本及辨識邏輯；Android 13+ 使用原生 Photo Picker 多選（系統上限），無法啟動時或較舊 Android 使用文件選擇器。根介面處理狀態列、導覽列、顯示切口及鍵盤 insets；批次顯示實際經過時間與每張辨識耗時平均值。更新前不必清除 003 資料。

## 005 啟動修正版
004 啟動閃退：移除 onCreate 早期直接存取 WindowInsetsController 的程式碼，沿用原主題系統列外觀，根 View 附著後才設定 safe-area；保留相片選擇器、耗時及原本 OCR、簽章、索引格式。實機閃退原因仍待驗證；未加大量掃描功能。

## 006 大量辨識
沿用 005 ML Kit 模型、簽章與安全邊距。SQLite WAL，逐張交易式寫入索引及待掃清單；保留舊 JSON 檔並一次性遷移。MediaStore 直接讀取相簿，預設最新 1000 張尚未索引的照片，也可選 3000/5000/10000/全部；相機與截圖依路徑辨識。已成功辨識（含無文字）且修改時間與大小相同者跳過，失敗項目可重新掃描。手動選圖與媒體庫不同 URI 可能重複；不做檔名猜測。關閉/離開 App 暫停，重新開啟按繼續，暫停時不計入總耗時。搜尋使用 SQLite Unicode 正規化子字串，分頁 100 筆，縮圖按可見列讀取。電量與電池溫度僅供參考。006 不是背景自動掃描，未刪除原始照片。

## 007 正式介面
006 的 IndexStore、ML Kit、簽章、相簿掃描與待處理資料庫保持不變。搜尋首頁清爽留白、暖白/青綠、最近搜尋（送出查詢或選取結果時記錄）、等寬縮圖網格、設定集中管理索引，手動更新可從首頁執行。全畫面照片檢視可雙指縮放、拖曳、分享原始 URI、複製或選取 OCR 文字。預覽使用最長邊約 3000 像素以下的取樣以控制記憶體；分享仍是原始檔。未加入 008 搜尋邏輯或 009/010 自動背景更新。
