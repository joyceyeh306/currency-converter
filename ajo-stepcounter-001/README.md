# ㄚ喬計步器 003

獨立 Android App，套件名稱 `tw.ajo.stepcounter`。使用 `TYPE_STEP_COUNTER` 硬體感測器，沒有定位、網路、帳號、Google Fit 或其他第三方套件。

## 功能
- 今日步數、大字首頁、每週及每月統計、每日明細、桌面小工具。
- 使用 Android **health 前景服務**維持感測器註冊，支援背景、開機重啟（系統允許時）與午夜切日。
- SQLite 原子化保存每天步數和硬體計數器基準。
- 透過 Android 文件選擇器匯出/還原 JSON 備份，還原會取代現有歷史。
- 可愛粉紫配色、等寬按鈕及觸覺回饋。

## 正確性邊界
1. **首次啟動只從第一次讀取的硬體數值建立基準**，不會把安裝前的步數猜成今日步數。
2. TYPE_STEP_COUNTER 僅在有 App 持續註冊時保證統計；ColorOS 或使用者強制停止、取消權限、手機關機期間的步數可能無法還原。
3. 橫跨午夜的長時間感測器空窗無法在沒有逐步時間戳的情況下精確分配。程式將收到增量記在事件日期，並在紀錄中顯示跨日空窗提醒。
4. 重開機或偵測到硬體計數器歸零時建立新基準，保留已記錄的當日累積值；重開機期間無法回補。
5. 小工具會隨感測器更新、日期切換廣播更新。ColorOS 深度省電可能延遲更新。首次使用需允許「身體活動」，建議在 OPPO 電池管理中允許背景活動。
6. JSON 還原後硬體基準重新開始，不會把同一段步數計兩次。
7. Android 17 / ColorOS 17 **尚須在實機完成長時間、跨日與重開機驗證**。

## 建置
在 `ajo-stepcounter-001/` 目錄執行：
```bash
gradle :app:assembleDebug
```
GitHub Actions 將建立簽章的 `assembleRelease` APK，並發佈到獨立分支的 `release/` 目錄。分支不影響 main 與現有 App。

## 發佈簽章
此系列版本使用 GitHub Actions 快取保存私有簽章檔。**GitHub 快取可能過期**，後續更新前必須保存原簽章憑證或搬到安全的私有保管方式；否則 Android 無法原地升級既有安裝。禁止將金鑰提交到公開 GitHub。

## 002 版修正
- 今日步數改為 Android 內建 casual 手寫感數字字體。
- 解決 Android 17 / ColorOS 17 狀態列與手勢列安全區域疊畫。
- 標題右側齒輪設定每日步數通知門檻，任意新增、修改與刪除（最多 30 個）。
- 每個門檻每天只提醒一次；感測器一次送來多筆累積時合併通知，避免洗通知。
- 保留 Android 要求的低干擾靜音前景服務通知，不再因每次感測器更新重新發佈。
- 可原地覆蓋 001：相同 Android package、資料庫結構與既有簽章（GitHub Actions 同分支快取）。
- 若不授權通知權限仍可計步，但收不到達標提醒。
